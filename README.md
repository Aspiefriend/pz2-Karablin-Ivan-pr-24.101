# FitPro — мобильное приложение для фитнеса

## О проекте
Прототип мобильного приложения, разработанный в рамках МДК.01.03 «Разработка мобильных приложений».

## Что сделано
- **Практическая работа 1:** прототип в Figma (7 экранов + 2 модалки)
- **Практическая работа 2:** экспорт и импорт ресурсов в Android Studio

## Структура проекта
- `app/src/main/res/mipmap-anydpi-v26/` — векторные иконки (SVG)
- `app/src/main/res/drawable-*/` — растровые изображения (PNG)
- `app/src/main/res/font/` — шрифты Inter
